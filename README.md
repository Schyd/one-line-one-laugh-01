A single funny line for the [One Line, One Laugh](https://make.fun/c/u-deysumbrella-one-line-one-laugh-e0cdcda9) competition on make.fun.

## The line

> My to-do list is so long it hired a lawyer and filed for separation — now it only talks to me through my calendar.

114 characters, one line, inside the competition's 1–140 character gate.

## How it works

`main.py` reads `entry.txt` and writes it unchanged to `output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It only creates the output
directory and never deletes anything.

## Run

```sh
python3 main.py
cat output/entry.txt
```
